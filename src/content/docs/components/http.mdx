The `NaN\Http` namespace provides implementations for PSR-7, PSR-15 and PSR-17 interfaces.

## Installation

```shell
composer require aimfornan/nan-http
```

## PSR-7 streams

### FileStream

```php
new NaN\Http\Streams\FileStream('file.ext', 'r+');
```

### InputStream

Reads from `php://input`.

```php
new NaN\Http\Streams\InputStream();
```

### OutputStream

Writes to `php://output`.

```php
new NaN\Http\Streams\OutputStream();
```

### ResourceStream

Takes in any resource.

```php
new NaN\Http\Streams\ResourceStream(\fopen('file.ext', 'r'));
```

### TempStream

Reads from and writes to `php://temp`.

```php
new NaN\Http\Streams\TempStream();
```

## PSR-7 messages

### Request

Body defaults to `TempStream`.
Headers default to empty array.

```php
new NaN\Http\Request(
	'POST', // HTTP method!
	'/', // URI!
	new NaN\Http\Streams\TempStream(), // body!
	[
		'content-type' => 'application/json',
	], // headers!
);
```

Parse cookies from cookies string.

```php
/**
 * @var string $cookies_header
 * @var array $cookies
 */
$cookies = Request::parseCookiesFromString($cookies_header);
```

### Response

Defaults to `TempStream` for response body.

```php
new NaN\Http\Response(
	204, // status code!
	'No Content', // reason phrase!
	[
		'Accepts' => 'application/json',
	], // headers!
	'1.1', // protocol version!
);
```

Get reason phrase for status code.

```php
$phrase = Response::getReasonPhraseForStatusCode(401);
```

JSON response.

```php
/** @var \Psr\Http\Message\ResponseInterface $response */
$response = Response::withJson($response, [
	'foo' => 'bar',
]);
```

Redirects. Status code defaults to `302`.

```php
/** @var \Psr\Http\Message\ResponseInterface $response */
$response = Response::withRedirect($response, '/', 307);
```

### ServerRequest

Defaults to `InputStream` for request body.

```php
new NaN\Http\ServerRequest(
	'POST', // HTTP method!
	'/', // URI!
	$_SERVER, // server parameters!
);
```

Getting headers from server parameters.

```php
$headers = ServerRequest::getHeadersFromServerParams($_SERVER);
```

Get a container service from request.

```php
/** @var ServerRequest $request */
$service = $request->getService(
	SomeInterface::class, // container service
	SomeClass::class, // default value
);

/** @var \Psr\Http\Message\ServerRequestInterface $request */
$service = ServerRequest::getServiceFromRequest(
	SomeInterface::class, // container service
	$request, // server request
	SomeClass::class, // default value
);
```

Check if request has a container service.

```php
/**
 * @var \Psr\Http\Message\ServerRequestInterface $request
 * @var bool $has_service
 */
$has_service = ServerRequest::requestHasService(
	SomeInterface::class, // container service
	$request, // server request
);
```

## PSR-15 request handlers

### ClosureRequestHandler

Turn a closure into a request handler.

```php
new \NaN\Http\Request\Handlers\ClosureRequestHandler(
	function () {
	},
);
```

### NoContentRequestHandler

Used to return a `204` response.

```php
new \NaN\Http\Request\Handlers\NoContentRequestHandler();
```

### NotFoundRequestHandler

Used to return a `404` response.

```php
new \NaN\Http\Request\Handlers\NotFoundRequestHandler();
```

## Request validators

All request validators take in one optional argument: an instance of `Nette\Schema\Elements\Structure`.

### CookieRequestValidator

If a schema is provided, will set the results in the request's cookie parameters.

```php
use \Nette\Schema\Expect;

new \NaN\Http\Request\Validators\CookieRequestValidator(
	Expect::array([
		'field' => Expect::string()->required(),
	]), // optional
);
```

### GetRequestValidator

Check if the request method is `GET`.
If a schema is provided, will set the results in the request's query parameters.

```php
use \Nette\Schema\Expect;

new \NaN\Http\Request\Validators\GetRequestValidator(
	Expect::array([
		'field' => Expect::string()->required(),
	]), // optional
);
```

### PostRequestValidator

Check if the request method is `POST`.
If a schema is provided, will set the results in the request's parsed body.

```php
use \Nette\Schema\Expect;

new \NaN\Http\Request\Validators\PostRequestValidator(
	Expect::array([
		'field' => Expect::string()->required(),
	]), // optional
);
```

### PutRequestValidator

Check if the request method is `PUT`.
If a schema is provided, will set the results in the request's parsed body.

```php
use \Nette\Schema\Expect;

new \NaN\Http\Request\Validators\PutRequestValidator(
	Expect::array([
		'field' => Expect::string()->required(),
```
